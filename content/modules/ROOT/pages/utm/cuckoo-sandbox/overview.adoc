= Общее описание решения Cuckoo Sandbox

Лабораторная работа «Установка и настройка Cuckoo Sandbox»

Требования: Linux Ubuntu 16.04.7, подключение к интернету.

Для установки cuckoo sandbox требуется python 2.7. На Linux Ubuntu 16.04.7 по умолчанию установлен и python 2.7.12, и python 3.5.2. Для проверки версии в терминале выполните:

[source,shell]
----
python -V
python3 -V
----
