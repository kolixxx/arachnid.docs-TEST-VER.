= Установка strongSwan

== Варианты установки

Обычно рекомендуется использовать бинарные пакеты, предоставляемые вашим дистрибутивом, поскольку это упрощает обслуживание. К сожалению, это часто означает, что вы не сможете пользоваться самой последней версией.

Альтернатива — сборка из исходников. Пошаговые инструкции для разных платформ приведены в официальной документации: link:https://docs.strongswan.org/docs/latest/install/install.html[Установка strongSwan].

== Установка из пакетов (Debian/Ubuntu)

На Debian и Ubuntu метапакет `strongswan` включает демон IKE `charon` и утилиту `swanctl` для управления через интерфейс `vici`:

[source,shell]
----
sudo apt-get update
sudo apt-get install strongswan
----

После установки проверьте доступность `swanctl`:

[source,shell]
----
swanctl --version
----

На системах с `systemd` демон обычно управляется службой `strongswan` или `strongswan-starter` (имя зависит от версии пакета в дистрибутиве). Глобальные параметры задаются в `/etc/strongswan.conf`, конфигурация соединений для `swanctl` — в каталоге `/etc/swanctl/`.

Подробнее о файлах конфигурации и сценариях настройки см. xref:ngfw/strongswan/configuration.adoc[конфигурацию и сценарии настройки strongSwan].
